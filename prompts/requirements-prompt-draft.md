Tour goal is to create a detailed guide for a Java developer to add a React front end for a spring application.

# Technologies used
The React application will use the following technologies:
- **React v19.1.1** React UI
- **React DOM v19.1.1**
- **Types React v19.1.1**
- **React Router Dom 7.7.1**
- **types/react 19.1.1** Type definition for react.
- **types/react-dom 19.1.1** Type definition for react-rom
- **Radix 3.2.1** React Component Library
- **Shadcn 2.6.3** Reusable component for Radix
- **Tailwindcss 4.1.10** CSS Framework for User Interfaces
- **tw-animate-css 1.3.4** A Collection of Tailwind CSS v4.0 utilities for creating beautiful animations
- **tailwind-merge 3.3.1** Utility function to efficiently merge Tailwind CSS in JS without style conflict
- **PostCSS 8.5.5** A tool for transforming styles with JS plugins
- **clsx 2.1.1** Utility for constructing className string conditionally
- **class-variance-authority 0.7.1**
- **lucide-react 0.515.0** Implementation of the lucide icon library for React application.
- **Autoprefixer 10.4.20** Plugin to parse CSS and add vendor prefixes to CSS rules 
- **Axios 1.10.0** Promised base HTTP client for the browser and Node.js
- **Node.js v22.17.1** JavaScript runtime for building the frontend.
- **types/node v24.0.1** Types for node.js
- **npm 10.9.2** Package manager for javascript.
- **TypeScript 5.8.3** Typed superset of JavaScript.
- **Vite 6.3.5** Module bundler for JavaScript applications.
- **vitejs/plugin-react 4.5.2** Vite plugin for React projects.
- **Jest 30.0.0** JavaScript testing framework.
- **types/jest 29.5.14**
- **testing-library/jest-dom 6.6.3**
- **testing-library/react 16.3.0**

# Vite Configuration
for development configure a proxy for Spring Boot server running on `http://localhost:8080`

The production build output path will be configured to use `src/main/resources/static`
